# Pluszzh.github.io

Minimal bilingual academic homepage for Zihao Peng.

## Local preview

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Publish

Push the files in this directory to the root of the public repository `Pluszzh.github.io`, then enable GitHub Pages from the `main` branch and `/ (root)`.
